# 实现结构

Skill、CLI、17 个类型化 MCP 工具共用 Engine 的会话锁。包内 capabilities.yaml 是唯一能力表。transport 只执行有界官方 WebSocket 协议；structure 管理参数/组/空容器；bindings 管理对象属性和眨眼配方；editor_ui/jab 管理 PID/版本/英文控件约束下的保存重开与导出；animation 生成线性动作/表情；runtime_check 使用用户提供的官方 SDK、Core 和本地浏览器执行独立验收。

原生写入：确认当前 UID/权限/模式/版本 → 快照与计划哈希 → 按端口的跨进程写锁 → 最后保存的 CMO3 备份 → 持久 recovery marker → EditBegin → 白名单请求 → 对象/结构回读 → EditEnd → 再回读。绑定额外验证非目标对象不变。UI 事务同样先备份和记录 marker，未知弹窗/焦点变化立即停下，不确认覆盖文件或丢弃修改。

客户端不自动重连并重放写入。不确定提交留下 marker；恢复工具只验证用户已恢复的备份和当前结构/公开属性，不猜测逆向几何。结构快照、对象属性和原生磁盘备份分别覆盖不同范围，均不能恢复未保存的任意美术。

文件生成只写输出目录，原子独占发布新动作/表情；更新 model3 前保留 JSON 备份并检查并发变化。SDK 验证器把必要资源复制到独立本地预览目录，回环监听，浏览器请求限制为该本地服务；结束关闭服务和浏览器。不开放 shell 字符串或任意编辑 API。

JAB 使用 Cubism 自带官方 bridge DLL，对单一监听 PID 枚举控件，不使用截图坐标。启用方式只作用于新 Editor 进程；不注入 JVM，不修改安装文件或全局 Java 属性。GUI 仅实现保存/重开/导出，PSD、模板、自由网格和物理创作仍为明确能力缺口。没有为这些功能放置假实现。
